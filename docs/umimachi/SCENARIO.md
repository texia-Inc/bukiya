# 海街スケート — シナリオ案

名前・設定はすべて仮。

## 舞台と主人公
- **舞台**：今の海街。坂の町、路面電車「うみまち線」、両端のトンネル、東西の峠、沖の島の灯台、西の山の紅白の電波塔、桟橋。
- **主人公**：汐見（しおみ）ナギ（仮）。夏休みに、電車で祖母のトメばあちゃんの家へやってきたスケボー少女。
- **物語の芯**：海街の時間を守ってきた「灯台の灯り」。どのルートも最後はここにつながる。

## 共通ルート（1〜3日目）
今あるおつかい（パン、花束、手紙、迷子の猫、写真）で町と住人を紹介しながら、3つの違和感をさりげなく見せる。
- 夜になると、電波塔が赤く点滅して妙な音を出す。
- 夕方だけ、桟橋に見知らぬ少女「ミオ」が立っている。
- 黒いバンが町を何度も通る。

**分岐**：3日目の夜、ナギはどうするか。
- 猫のおもちを追って、西のトンネルへ → **ホラールート**
- 黒いバンを追って、港へ → **悪の組織ルート**
- そのまま寝る → **のほほんルート**

それまでに誰と仲良くなったか、どこで写真を撮ったかといった記録で、選べる選択肢や展開が少し変わる。

## ルート
### ① のほほんルート「なつやすみ帳」
- 住人の頼みごとを聞いて回りながら、神社の夏祭りに向けて町を飾りつけていく。
- 山場は桟橋のスケボー大会と、海の上の花火。
- エンディングで、ナギは「海街の配達係」になる。
- 新しく作るものがいちばん少なく済む。

### ② ホラールート「トンネルの向こう」
- 夜のトンネルを抜けると、30年前で時間が止まった「裏海街」に出る。
- 運転手のいない終電、顔のない住人、行方不明になった子どもの噂。
- 遊び方：懐中電灯での探索、隠れながら進む場面、スケボーでの逃走。
- ミオの正体と、灯台の灯りが消えた夜の真相に近づく。

### ③ 悪の組織ルート「シーサイド・コンスピラシー」
- リゾート開発会社「オーシャンゲート社」が、電波塔で町を監視し、灯台を壊そうとしている。
- 仲間：子どもたちのグループと、実は元エージェントだった「こむぎ堂」の店主。
- 戦い方は殴り合いではなくスケボーの技。ジャンプでドローンを落とす、手すりを滑って追っ手を振り切る、社員を巻いて逃げる追跡戦。
- ボス戦も追いかけっこ型。

### ④ 真ルート「灯台」
- 3つのルートを全部クリアすると開く。
- 電波塔の信号、トンネルの時間のずれ、会社が狙う「灯り」がつながり、ナギが町に来た本当の理由（母の過去）が明かされる。

## 拡張の提案（おすすめの順）
1. **シナリオを動かす仕組み（最優先）**
   - 日付と昼夜（夕方・夜は空や灯りが変わる）
   - 会話中の選択肢と、選んだ結果の記録
   - イベントをプログラムではなくデータとして書ける形にする
   - イベント用のカメラ演出、複数のセーブ枠
2. **マップ**
   - 裏海街：今の町を夜・霧・色あせた色調に作り変えて再利用（安く作れてホラーとして効く）
   - 沖の島と灯台：真ルートの舞台。桟橋から船で渡る
   - 港の工業地帯：組織の拠点。トンネルの先
   - 祭りの日の海街：今の町に提灯と屋台を足す
3. **アクション**
   - スケボーの技を増やす（グラインド、キックフリップ、ウォールライド）と技のスコア
   - 追跡戦、隠れながら進む場面、懐中電灯
4. **やり込み**
   - 着せ替えとガチャ（実装済み。衣装セットを増やしていく）
   - 猫探し、写真スポットの追加
   - 桟橋の釣り、時間内に届けるパン配達、峠からのタイムアタック

## 作る順番の案
1. シナリオを動かす仕組み
2. 共通ルート（今のマップのままで作れる）
3. のほほんルート
4. ホラールート（裏海街は今の町の再利用）
5. 悪の組織ルート（追っ手の動きを新しく作る必要がある）
6. 真ルート
