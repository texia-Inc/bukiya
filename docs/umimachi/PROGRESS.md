## できていること

### 町
- 海へ下る坂の町。通り8本、名前のある店10軒（こむぎ堂、駄菓子まるや、花のはなもり、喫茶しおさい、魚松、八百吉、古書うみねこ、郵便局、食堂なぎさ、潮騒ホテル）と一般の家・アパート
- 電柱と電線、カーブミラー、標識、横断歩道、自販機、ポスト、商店街のアーチ
- 路面電車「うみまち線」（線路に沿って往復）、遮断機の下りる踏切、うみまち駅
- 丘の上の神社と見晴らし台。海辺の堤防、浜辺、海の家、監視台、桟橋、沖の島の灯台
- 町の東西の端：線路と海岸通りがトンネルに入る。浜の両端は岩とテトラポッド
- 東西の山：森（広葉樹と杉）に覆われ、尾根まで登れる。尾根には「東の峠 見晴らし」「西の峠 見晴らし」のデッキ（町側の木は景色のために除いてある）
- 走る車：セダン、軽自動車、ワゴン、軽トラ、タクシー

### 主人公
- 汐見ナギ（仮）：VRoid Studio で作ったモデル（夏の制服、高いポニーテール、琥珀色の目）を Blender で改変。まばたき・笑顔などの表情あり
- 設定画：`tools/umimachi/design/`（全身4面・表情・小物）、作り方：`tools/umimachi/VROID_GUIDE.md`
- 手続き生成の骨組み（見えない）が姿勢を計算し、モデルの骨を合わせる。腕は肘と手の位置へ、脚は2ボーンIKで足をデッキに固定、ひじ・肩の補助ボーン（VRMの制約）があれば計算
- モデルを読み込めなかったときは、以前の手続き生成キャラで動く

### スケボー
- 地面を蹴って加速（押し続けると蹴り続ける）。坂は勝手に転がる、ブレーキ、カーブ
- 乗り方はレギュラースタンス（左足前、後ろから見て右向き）。蹴るときだけ正面を向き、前脚を伸ばして右足で蹴る
- ジャンプ（約2.1m、滞空約1.1秒）はオーリー：ノーズを弾き、膝と板を引き上げ、後ろの手でインディーグラブ
- 登れる場所：堤防、ベンチ、車の屋根、駅のホームと屋根、坂の途中の屋上、峠の見晴らし台

### 降りて走る
- F キー（スマホは「降りる」）：テールを踏んで板を立てて止まり、ノーズを手で持つ
- 動き出すと板を背中に背負って走る（最高 約7.5m/s）。前傾、肘を曲げた大きな腕振り
- もう一度押すと板を前に置いて飛び乗る
- マントや羽を着ているときは、板を手に持ったまま走る

### ドローン迎撃（2丁拳銃）
- 「メロンパンをふたつ」を終えたあと、こむぎ堂の主人（元エージェント）に話すと始まる。オーシャンゲート社の監視ドローン12機を撃ち落とす（1機50円、全部で +1000円）
- 2丁拳銃は主人公モデルの部品（`Gun_L` / `Gun_R`、握った手に持つ）。イベント中だけ出る。近くのドローンを自動でねらい、両腕をまっすぐ向けて左右交互に撃つ
- 銃口の光、弾の軌跡、薬莢、命中の火花、墜落と爆発。構えている間はカメラが肩越しになる
- スケボーに乗っているときと、板を背負って走っているときに撃てる（板を手に持っているときは撃てない）
- 一度クリアすると、こむぎ堂の主人はふつうにパンを売る。試すときは `index.html#drones` で始めるとすぐ始まる

### 着せ替えとガチャ（PR #31）
- 服は主人公モデルの部品（`W_<名前>`）。スロット：トップス／えり元／ボトムス／くつ下／くつ／手／あたま／シュシュ／せなか／こし／髪の色
- 色の掛け替えと柄（迷彩・しましま・水玉・星柄）
- 衣装セット：ハロウィン魔女、黒ねこ、ミリタリー、小悪魔、天使、セーラー
- VRoid の服の取り込み：同じナギを VRoid で別の服に着替えさせて書き出し（`tools/umimachi/design/outfits/`）、服だけを部品にする。今はパーカー・Tシャツ（白で書き出し、色や柄はゲームで付ける）と浴衣・下駄（ガチャのスーパーレア。着ている間はボトムス・くつ下・くつ・えり元を隠す）
- ガチャ：駄菓子まるやの店先のカプセルトイ。1回100円・5連。スーパーレア5%／レア25%／ノーマル70%。景品は「服×色」で119種類
- ダブりは「かけら」になり、持っていない物と交換（ノーマル5／レア15／スーパーレア40）。セットごとの集まり具合を表示
- 「着がえ」画面（C キー）では持っている物だけ選べる

## 操作
| パソコン | スマホ | 内容 |
|---|---|---|
| W / ↑ | ける | 地面を蹴る（降りているときは走る） |
| S / ↓ | スティック下 | ブレーキ |
| A D / ← → | スティック左右 | 曲がる |
| Space | ジャンプ | ジャンプ |
| F | 降りる／乗る | スケボーを降りる・乗る |
| E | 話す | 話す・お店に入る・ガチャを回す |
| C | 着がえ（画面右） | 着がえ |
| Q ・ P | 画面右のボタン | おつかい帳・写真を撮る |
| J ・ クリック | 撃つ（ドローン迎撃のときだけ） | 撃つ |

## 開発の手順
1. `tools/umimachi/src/` のファイルを編集する
2. `cd tools/umimachi/src && python3 build.py` で `docs/umimachi/index.html` を作り直す（1ファイル版 `umimachi_single.html` も作られる。コミット対象外）
3. 手元で遊ぶ：`cd docs/umimachi && python3 -m http.server` → http://localhost:8000
4. 服の部品を変えたとき：`cd tools/umimachi && Blender -b --python heroine_vrm.py -- design/nagi.vrm ../../docs/umimachi/heroine.glb`
