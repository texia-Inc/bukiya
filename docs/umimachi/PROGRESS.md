## できていること

### 足もと
- 歩道（車道より12cm高い）では、ナギも町の人も歩道の上に立つ（前は足がめりこんでいた）
- 神社の拝殿は坂に建っているので、石段を6段にして地面までとどかせた。1段ずつのぼれる。賽銭箱は石段の前の地面に
- 参道の敷石は坂にそって置く

### 設定とあそびかた
- 右の「設定」（スマホは「メニュー」の中）：音のオン・オフ、音の大きさ、振動（アプリのみ）、画質（軽い／ふつう／きれい：解像度・草・影）、あそびかた、タイトルにもどる
- タイトルには操作の説明を出さない。はじめて遊ぶときに「設定 → あそびかた」で見られると知らせる
- アプリのアイコンは、ゲームの中で撮ったナギ（夕方の桟橋、うしろに灯台の島）。`app/icon_shot.jpg` から `make_icons.py` で作る

### 木と草（`p2b_nature.js`）
- 広葉樹はいくつかのかたまりを合わせたでこぼこの樹冠（下が暗く上が明るい）、杉と島の松は段になった枝。風で木全体がゆれ、葉が小さくふるえる
- 草：自分のまわり（パソコン42m、スマホ30m）だけ、16m四方ずつ作って遠くは消す。道・建物・空き地の予約・線路・浜・切り通しには生えない
- 海から風が吹いて、草がゆっくりなびく。草の上のつやは、ほんのり
- **野の花**：草の中に、ところどころまとまって咲く小さな花（白・クリーム・黄・ピンク・うす紫・空色、五弁で真ん中が黄色）。茎ごと風でゆれる
- **風の線**：草の上の空中に、白い細い線が風にのって流れる（ゆれながら進み、ときどきくるっと輪を描く。2〜3秒で出て消える）。パソコン7本、スマホ4本まで。昼ほどはっきり、夜は見えない。画質「軽い」と裏海街ではなし
- 道、島の灯台への道と桟橋には草を生やさない
- 町の両わきの丘は、海の先で岬になって海に沈む（前は板を切ったように終わっていた）。地面は遠い山の下まで広げた

### iPhone アプリ（`tools/umimachi/app`）
- Capacitor で包んだアプリ。three.js とフォントも中に入れていて、ネットなしで動く。iPhone のみ、縦横どちらでも
- スマホ（Web 版も）のタイトルは、キーの一覧のかわりにボタンの説明。会話の「クリックか J キーで」「P キーか」なども、スマホではボタンの名前になる
- 2本指でつまむ・2回タップで画面が拡大されて戻らなくなるのを止めた（アプリは WebView の拡大自体を切る）
- 横向きでも、左上・地図・ボタンが切り欠きにかからない
- セーブ（umimachi_*）はアプリ本体の設定にも控えを残し、WebView 側が消えても起動時に戻す
- アルバムの写真をタップすると共有シート（「画像を保存」で写真アプリへ）。写真は 640px に
- 着地・ぶつかる・お金・写真・勝ち負け・ドローンに撃たれたときに振動（音がオフでも）
- ホームに戻るときにセーブ。戻ってきたら音を再開（iOS が音を止めたままにしたときは、次に画面にさわったときに音を作り直す）。画面の端からのスワイプは2回で（スティック操作でアプリを閉じない）

### スケボー
- 地面を蹴って加速（押し続けると蹴り続ける）。坂は勝手に転がる、ブレーキ、カーブ
- 乗り方はレギュラースタンス（左足前、後ろから見て右向き）。蹴るときだけ正面を向き、前脚を伸ばして右足で蹴る
- ジャンプ（約2.1m、滞空約1.1秒）はオーリー：ノーズを弾き、膝と板を引き上げ、後ろの手でインディーグラブ
- 登れる場所：堤防、ベンチ、車の屋根、駅のホームと屋根、坂の途中の屋上、峠の見晴らし台

### スケボーの技
- 空中で K（スマホは「技」）：キックフリップ。曲がりながらなら360ショービット。ボードが回りきる前に着地すると転ぶ
- 高いジャンプでは自動でインディーグラブ
- **グラインド**：手すりの上に着地すると、手すりをすべる（坂では加速、火花が出る）。Space で飛び降りる。遅くなると横に降りる。手すりは「海へつづく坂」の両側（交差点ごとに切れている）と、桟橋の手すり
- 技を決めると、画面の上に技の名前が出る（点数はない）
- スマホの左スティックは、左下のどこでも触ったところに出る（フローティング）。前に倒すと進む
- スマホで降りて歩くときは、スティックを倒した画面の方向へ歩く（少し倒すと歩き、深く倒すと走る）。カメラは前へ歩くときだけゆっくり後ろへ回りこむ。スケボーのときは今までどおり、左右で曲がる
- スマホの「話す」ボタンは、近くに話す相手や調べるものがあるとき（会話中は「次へ」）だけ出る

### 降りて走る
- F キー（スマホは「降りる」）：テールを踏んで板を立てて止まり、ノーズを手で持つ
- 動き出すと板を背中に背負って走る（最高 約7.5m/s）。前傾、肘を曲げた大きな腕振り
- もう一度押すと板を前に置いて飛び乗る
- マントや羽を着ているときは、板を手に持ったまま走る

### ドローン迎撃（2丁拳銃）
- 悪の組織ルートの4日目、こむぎ堂の主人（元エージェント）の話のあとに始まる。オーシャンゲート社の監視ドローン12機を撃ち落とす（1機50円、全部で +1000円）
- **どのルートでも山場になる**（出来事の `drones`）：小さいドローンの群れのあと、4倍の大きさの**大型ドローン**（60発で落ちる）。三方向に同時に撃ってきて、護衛を2機ずつ呼ぶ。上に棒で体力が出る。やられたら、その段階（群れ／大型）からすぐやり直し
  - のほほんルート：夏祭りの花火の最中に現れる（こむぎ堂の主人が拳銃を貸してくれる）。海岸通りで戦って、花火の続き
  - ホラールート：3つの手がかりのあと、裏海街に「影のドローン」。足もとに落ちていた古い二丁拳銃で戦い、そのあと大きな影の追いかけっこ
  - 悪の組織ルート：最後の夜、バンを追う前に黒崎の大型ドローン「ガーディアン」
  - 真ルート：島に着くと、灯台の下の機械から大型ドローンが飛び立つ
  - 物語のドローン戦が始まるとき、板を手に持っていたら背中に背負う（すぐ撃てる）
- 2丁拳銃は主人公モデルの部品（`Gun_L` / `Gun_R`、握った手に持つ）。イベント中だけ出る。近くのドローンを自動でねらい、両腕をまっすぐ向けて左右交互に撃つ
- 銃口の光、弾の軌跡、薬莢、命中の火花、墜落と爆発。構えている間はカメラが肩越しになる
- スケボーに乗っているときと、板を背負って走っているときに撃てる（板を手に持っているときは撃てない）
- ドローンも撃ち返してくる。目が光って赤い線でねらってから（0.7秒）、行く先を読んだ赤い弾を撃つ。撃つのは一度に1機ずつ（0.9秒おき）。止まっていると当たり、走りながら曲がるとよけられる
- 体力は5（♥）。当たると画面のふちが赤くなり、少し揺れて減速する。0になるとドローンが引き上げて失敗。4日目の戦いは、こむぎ堂の主人にもう一度話すとやり直せる
- いつでも始められる寄り道ではなくなった。試すときは `index.html#drones` で始めるとすぐ始まる

### シナリオを動かす仕組み
- **日付と時刻**：左上に「1日目・朝」のように出る。朝（5〜10時）・昼（10〜16時）・夕方（16〜19時）・夜（19〜5時）
  - 時計は遊んでいる間ひとりでに進む（75秒で1時間）。ただし「その日の上限」（ふだんは15時半）で止まり、その先は出来事が進める
  - 空の色、霧、光の色と向き、太陽の高さが時刻で変わる。夜は星、家の窓の明かり、海岸通りの街灯、桟橋の灯り、島の灯台（回る光）、電波塔の赤い点滅
- **出来事（イベント）**：プログラムではなくデータで書く（`p5d_events.js`）。話しかけたとき・場所に近づいたとき・条件がそろったときに始まる。書き方はそのファイルの先頭と `p5c_story.js` の `step` にある
  - できること：会話、選択肢（ボタン、1〜4キー）、フラグ（仲良し度などの数）、条件分岐、時刻を進める、次の日にする、暗転、カメラ演出（上下の黒帯つき）、待つ、移動、お金・アイテム、おつかいを始める
  - 出来事の間はスケボーが止まり、画面のボタン類が隠れる
- **セーブ枠**：タイトルで3つから選ぶ（日付・時刻、所持金、おつかいの数、最後に遊んだ日時が出る）。「消す」は2回押すと消える。前からのセーブはセーブ1に入る。アルバムは共通
- 試すとき：`index.html#storytest` で確認用の出来事が始まる。`#hour=20` で時刻を20時に、`#at=-80,330` でその場所から、`#day=3` でその日の朝から始まる、`#set=route:3,met_mio:1` でフラグを立てる、`#racelimit=5` でレースを5秒で打ち切る（`&` でつなげる。例 `#day=6&set=route:3&at=-71,261.5`）

### 共通ルート（1〜3日目）
- おつかいを追っていないときは、左上に「今日のめあて」が出る（次にやることを1行で）。時計は時刻（16:30 など）も出る
- おつかいをいくつも受けているときは、左上の追っているおつかいの下に、ほかのおつかいが番号つきで並ぶ（4件まで。タップでそちらを追う）。地図にも同じ番号と色の印が全部出る（追っているものは大きい）
- 神社の三毛猫（ミケ）は拝殿の石の台の角にいる。夜は丸くなって眠り、なでたときの言葉も朝・昼・夕方・夜で変わる
- 2日目からは、昼のうちにばあちゃんに話すと「夕方まで、ひと休みする」を選べる
- 夕方にトメばあちゃんに話すと「家に帰る」を選べる。その夜の出来事のあと、次の日の朝になる（ばあちゃんのベンチの前から）
- 1日目は「メロンパンをふたつ」を届けると夕方になる。2日目からは、時計が15時半に着くと夕方になる。暗くなると「ばあちゃんのところへ帰ろう」と出る
- **1日目**：坂の上に着く場面 → ばあちゃんに会っておつかい → 夕方、桟橋の先で白いワンピースの少女（ミオ）。目を離すと消える。釣りのおじさんは「誰も来とらん」 → 夜、電波塔の赤い点滅と雑音
- **2日目**：朝、ばあちゃんと話す（ゆうべのこと、ミオのこと） → 黒いバンに近づくと気づく → しおさいのマスターに聞くと「オーシャンゲート社」 → 浜で白い猫「おもち」に会う → 夕方、ミオが名前を名乗り「30年前、灯台の灯りが消えた」 → 夜、ばあちゃんから灯台と、30年前にいなくなった子と、母の話
- **3日目**：ソウタくんにスケボー大会に誘われる、黒いバンが灯台を撮っている話 → こむぎ堂の主人が「黒崎には近づくな」 → 夕方、ミオが「今夜、扉が開く」 → 夜、分かれ道
- **分かれ道**：おもちを追って西のトンネルへ（ホラー）／黒いバンを追って港へ（悪の組織）／そのまま寝る（のほほん）。会ったもの・聞いたことで選択肢の言葉が変わる（おもちに会っていなければ「白い猫」、バンを知らなければ「外の物音」）。選んだルートは `route` に記録される（1 ホラー、2 組織、3 のほほん）。ルートの中身はまだなので、いまは4日目の朝になる
- ミオのモデルは VRoid Studio で作った（黒髪のボブ、白いノースリーブのワンピース、白いサンダル、150cm、色白）。後ろで手を組んで立ち、ゆっくり息をして、少しうつむき、ナギが近づくと顔を向ける
- ミオは夕方だけ桟橋の先にいる。島の灯台は30年前から消えている設定なので、夜も光らない（`lighthouse_lit` を立てると光る）
- 記録しているもの：おつかいを終えると `bond_<人>` が増える。ほかに `bond_mio`、`bond_mochi`、`bond_sota`、`met_mio`、`met_mochi`、`saw_tower`、`saw_van`、`heard_og`、`heard_kurosaki`、`heard_lighthouse`、`promise_contest`、`mio_warn`

### のほほんルート「なつやすみ帳」（3日目の夜に「そのまま寝る」、4〜6日目）
- 4日目の朝、ばあちゃんが「あさって（6日目）は夏祭り」と話す。町の人の祭りの手伝いが、おつかいに加わる
  - 「提灯をつるそう」（古書うみねこの店主＝町内会長）：提灯を参道につるす → 参道と商店街と坂に提灯が飾られる。夜は灯る
  - 「屋台のみかん氷」（魚松のおかみさん）：みかんを2袋 → 参道に屋台が6つ出る（かき氷・やきそば・りんご飴・たこ焼き・金魚すくい・射的）。お祭りの前は屋台だけが立っていて、お店の人はお祭りの日（6日目）だけ。7日目からは提灯も屋台も片づく
- **夏祭りの日（6日目）のにぎわい**（`p5e_festival.js`）：浴衣の人が参道・坂道・商店街を歩き、屋台の前や鳥居のそばで立ち話。風船を持った子ども。屋台ごとにお店の人とのぼり
  - 屋台で E：食べ物（かき氷200・やきそば400・りんご飴250・たこ焼き400円）はその場で食べる。4つ全部食べると「ぜんぶ食べた！」
  - 金魚すくい（300円）：水に指を入れて金魚の下へ、はなすとすくう。水の中では少しずつ、動かすともっとポイが弱る。大きい黒い金魚は重い。1匹以上すくうと金魚を1匹もらえる
  - 射的（300円）：コルク5発。照準はゆれる。上のほうに当てると倒れやすい。景品はキャラメル・けん玉・ラムネ・くまのぬいぐるみ
  - 夜は参道に暖かい明かり（ライト3つと提灯・屋台の光）。神社の近くで祭りばやし（太鼓と笛）と人のざわめき
  - 「お祭りの浴衣」（はなもりの花江さん → トメばあちゃん）：母が着ていた浴衣。着がえで浴衣が着られるようになる
- 4〜5日目はソウタくんに話すと、大会のコースを練習できる（タイムと自己ベストが出る）
- 6日目：朝、祭りの飾りが全部そろう。ソウタくんに話すとスケボー大会
  - **大会**：見晴らし台から桟橋の先までの坂下りレース。左上にタイム。55秒以内で優勝（+1000円）、68秒以内で2位、80秒以内で3位、それより遅いか150秒を過ぎると参加賞
  - そのあと夜、桟橋から海の花火（60秒）。花火の最中にドローンが来て、海岸通りで大型ドローンと戦う。終わると花火の続き。ミオに会っていれば、隣で花火を見上げている。ばあちゃんに「海街の配達係」を頼まれて、のほほんルートおしまい（`ending_calm`）。そのあとも遊び続けられる
- 新しい仕組み：おつかいの「置く」手順（決まった場所で E）、坂下りレース（出来事の `race`）、花火（`fireworks`）、おつかいの出る条件（`when`）

### ホラールート「トンネルの向こう」（3日目の夜に「おもち（白い猫）を追う」）
- その夜のうちに、西の海岸トンネルを抜けて「裏海街」へ。30年前で止まった町：色がなく、霧が濃く、窓の灯りがない。知っている人はいない。だれも乗っていない電車だけが走る
- **探す**：3つの手がかり（駅のホームの古い写真、駄菓子まるやのビー玉、神社の本殿の日記）。青白く光る場所に近づくと調べられる。左上に残りが出る
- **隠れる**：顔のない「影の住人」が8人、通りを行き来している。前方が見えていて、見つかりかけると目が赤く光り、画面のふちが赤くなる。見つかりきると、トンネルの出口に戻される（手がかりはそのまま）
  - スケボーで速く走ると音で、ライトをつけると光で見つかりやすい。降りて歩く（F）と見つかりにくい
- **ライト**：L キー（スマホは右の「ライト」）。裏海街の中だけ
- **逃げる**：3つそろうと影のドローン戦、そのあと大きな影が現れて追ってくる。西のトンネルまで逃げる
  - 大きな影は耳と目で探す：スケボーの音は40m先まで聞こえる、歩く足音は9m、前方20mは見える。見つけると走って追い（だんだん速くなる）、見失うと最後にいた場所へ行って、立ち止まってにおいをかぎ、また近くをうろつく。遠く離れても、霧の中から近くに出てくる
  - **音**：大きな影のズシンという足音とうなり声が、近いほど大きく速くなる。30mより近いと心臓の音。見回りの影の住人の足音も、近いほど大きい
  - **木箱に隠れる**：通りに置かれた大きな木箱（22か所）の近くで E。中から木箱のふたごしに外を見る。A・D（スマホはスティックの左右）で見回せて、手をはなすと影のほうへ向き直る。入るところを見られていなければ、影はすぐ横まで来ても気づかずに通り過ぎる。E で出る。見回りの影の住人からも隠れられる
  - 左上の「気配」の■が近さ。つかまると、まず横からの短いリプレイ（最後の2秒、つかまる瞬間はスローで、上の黒帯に「● リプレイ」）。そのあと最後に隠れた木箱（まだなら追いかけっこの始め）に戻る
  - 3回つかまるごとに「もう少しがんばる／先に進む（リタイア）」を聞く。リタイアすると、トンネルまで逃げきったことにして物語が進む（苦手な人が詰まないように）
  - 振り返る：パソコンは R を押しているあいだ、スマホは左の「振り返る」ボタン。ナギの頭のうしろから来た道を見る（ナギは映らない）。追ってくる影がどこまで来ているかがわかる
- 夜明けの桟橋で、ミオが正体を明かす：30年前の夏、ナギの母ナツミの友だちで、あの夜トンネルの向こうへ行ったまま帰れなくなった。灯台の灯りがともれば帰れるかもしれない。ホラールートおしまい（`ending_horror`）、4日目の朝へ
- 裏海街の中でセーブして開き直すと、裏海街の中から（坂の上から）始まる

### 着せ替えとガチャ（PR #31）
- 服は主人公モデルの部品（`W_<名前>`）。スロット：トップス／えり元／ボトムス／くつ下／くつ／手／あたま／シュシュ／せなか／こし／髪の色
- 色の掛け替えと柄（迷彩・しましま・水玉・星柄）
- 衣装セット：ハロウィン魔女、黒ねこ、ミリタリー、小悪魔、天使、セーラー
- VRoid の服の取り込み：同じナギを VRoid で別の服に着替えさせて書き出し（`tools/umimachi/design/outfits/`）、服だけを部品にする。今はパーカー・Tシャツ（白で書き出し、色や柄はゲームで付ける）と浴衣・下駄（ガチャのスーパーレア。着ている間はボトムス・くつ下・くつ・えり元を隠す）
- 真ルートのクリア後は、夕方のあとも時計が夜まで進む（23:54まで。「日が暮れていく。夜の町と、灯台の光を見に行こう」）。ばあちゃんに話せば家に帰って次の日。それまでは夕方18:54で止まり、帰るまで夜にならない
- 肉球てぶくろとドッグタグは、モデルの部品ではなくゲームの中で作って骨にくっつけている（`p4c_wardrobe.js` の EXTRAS）：てぶくろは手よりひと回り大きい猫の手（指先に4つの指、手のひらにピンクの肉球、手首にふわふわ）。ドッグタグは首にかけた鎖と、胸の前の2枚のタグ（NAGI の刻印）
- 髪の色：いつもの髪（黒）の色見本は黒。2番目の色は、黒と見分けのつかない暗い色だったので、はっきりした茶色にした
- スニーカーの色は、くつ底を残して全体に付く（前は暗い所だけが変わっていて、ほとんど見えなかった）。いつものくつは白
- 浴衣のときは足首から腰まで、スカートのときはスパッツのすそから上の脚の肌を描かない（スケボーでひざを曲げると、肌が布から飛び出していた）。体のりんかく線も同じ所だけ消す
- マントもゲームの中で作る：肩からひざまでの長い布（裏地は赤。赤いマントなら黒）、立ちえり、金の留め具とひも。首の後ろからいつも下へ垂れ、スピードやジャンプで後ろへなびく（`driveVRM` の最後で動かす）
- リボン（えり元とセーラーえり）もゲームの中で作る：ふくらんだ左右の羽、結び目、先が切れこんだ2本のたれ
- ガチャ：駄菓子まるやの店先のカプセルトイ。1回100円・5連。スーパーレア5%／レア25%／ノーマル70%。景品は「服×色」で119種類
- ダブりは「かけら」になり、持っていない物と交換（ノーマル5／レア15／スーパーレア40）。セットごとの集まり具合を表示
- 「着がえ」画面（C キー）では持っている物だけ選べる。選ぶとすぐ着がえ、板の上のあいた所にナギの全身が映る（屋台などに隠れない。めあて・地図・ボタンは隠す）
  - 上のナギはドラッグで回せる（後ろ姿も）、上下で見上げ・見下ろし。ピンチ（マウスはホイール）で拡大すると顔のほうへ寄る
  - 「大きく見る」：一覧がたたまれて下の細い帯になり、ナギが画面いっぱいに映る（お金・時計も隠す）。帯の ‹ › で場所（トップス・えり元…）と服を切りかえ、色の丸で色。背景（町・白・夕やけ・夜）、くるくる（自動で回る。ドラッグで止まる）、正面、撮る（アルバムへ）。「一覧へ」で戻る

## 開発の手順
1. `tools/umimachi/src/` のファイルを編集する
2. `cd tools/umimachi/src && python3 build.py` で `docs/umimachi/index.html` を作り直す（1ファイル版 `umimachi_single.html` も作られる。コミット対象外）
3. 手元で遊ぶ：`cd docs/umimachi && python3 -m http.server` → http://localhost:8000
4. iPhone アプリ：`cd tools/umimachi/app && npm run sync && npm run open`（three.js とフォントもアプリの中に入れる）
5. 服の部品を変えたとき：`cd tools/umimachi && Blender -b --python heroine_vrm.py -- design/nagi.vrm ../../docs/umimachi/heroine.glb`
