# 武器屋放置ゲーム MVP設計

## 1. MVP の基本方針

### 目標と成功指標
```
主目標:
- 核心的なゲームループの検証
- ユーザーの継続率測定（Day1: 70%, Day7: 30%）
- 基本的な課金システムの効果測定

検証したい仮説:
1. 冒険者との取引システムが魅力的か
2. エンチャントシステムが継続動機になるか
3. 時間制限による課金誘導が適切か
4. 放置要素とアクティブ要素のバランス
```

### MVP期間とリソース
```
開発期間: 3-4ヶ月
チーム規模: 2-3名（1名フロント、1名バック、0.5名デザイン）
予算規模: 小〜中規模
技術スタック: Flutter + Python FastAPI + PostgreSQL
```

## 2. MVPに含める機能（コア機能）

### A. 基本ゲームループ（必須）

#### 武器システム（簡略版）
```
武器種: 3種類のみ
- 剣（バランス型）
- 弓（クリティカル型）  
- 杖（魔法型）

レア度: 3段階
- Common ★☆☆
- Rare ★★☆
- Epic ★★★

エンチャント: +0〜+10まで
- 成功率: +1〜+5は100%、+6〜+10は90%〜70%
- 効果: 攻撃力+1/レベル
- エフェクト: +5以上で青色エフェクト（簡易版）
```

#### 冒険者システム（簡略版）
```
冒険者の種類: 5種類
- 基本ステータスと要求のみ
- 信頼度システムは後回し
- 専門性は簡略化

取引フロー:
1. 冒険者来訪（要求提示）
2. 武器選択・販売
3. 冒険実行（1-4時間）
4. 帰還・素材買取提案
5. 買取判断（時間制限30分）

派遣先: 3エリア
- 森林（初級）
- 洞窟（中級）
- 山岳（上級）
```

#### 錬成システム（基本版）
```
基本素材: 5種類
- 鉄鉱石、銅鉱石、魔法石、強化石、レア鉱石

基本レシピ: 各武器種×レア度（9種類）
- 固定レシピのみ
- 成功率100%（失敗なし）
- 錬成時間: 5分〜2時間
```

### B. 基本UI/UX（必須）

#### 画面構成（5画面）
```
1. ホーム画面
   - ゴールド表示
   - 進行中の活動表示
   - 緊急買取案件表示
   - クイックアクション

2. 冒険者画面  
   - 現在の訪問者リスト
   - 取引・派遣管理
   - 帰還待ちリスト

3. 工房画面
   - 武器錬成
   - エンチャント

4. 倉庫画面
   - 武器・素材一覧
   - 基本的なソート・フィルター

5. 設定画面
   - 基本設定のみ
```

#### 課金システム（基本版）
```
ジェム購入:
- 100ジェム = 120円
- 500ジェム = 490円  
- 1000ジェム = 860円

使用用途:
- ゴールド購入（1ジェム = 100G）
- 時短（1分 = 1ジェム）
- 倉庫拡張（+10枠 = 100ジェム）
```

### C. 放置システム（基本版）

#### オフライン進行
```
対象システム:
- 冒険者の派遣進行
- 錬成作業の進行
- 時間経過によるゴールド微増

上限設定:
- 12時間分まで蓄積
- 超過分は無効

通知:
- 派遣完了通知
- 錬成完了通知
- 買取期限警告
```

## 3. MVPで除外する機能（Phase2以降）

### 除外するシステム
```
❌ 属性システム（火・氷・雷・土・風）
❌ アビリティシステム（特殊効果）
❌ 武器分解・改造システム
❌ セット効果システム
❌ プレイヤー命名権
❌ ランキングシステム
❌ ソーシャル機能
❌ ギルドシステム
❌ 複雑なモンスターシステム
❌ 季節イベント
❌ 自動バランシング
❌ 高度なエフェクト・アニメーション
```

### 簡略化するシステム
```
🔶 武器生成: 固定レシピのみ
🔶 冒険者AI: 基本的な要求パターンのみ
🔶 エンチャントエフェクト: 色変化のみ
🔶 価格システム: 固定価格（変動なし）
🔶 バランシング: 手動調整のみ
```

## 4. MVP開発フェーズ計画


## 5. MVPでの数値設計（簡略版）

### 武器バランス
```
Common武器:
- 攻撃力: 50-150
- 錬成コスト: 100G + 基本素材×2
- 錬成時間: 5分

Rare武器:
- 攻撃力: 120-300
- 錬成コスト: 500G + 中級素材×3
- 錬成時間: 30分

Epic武器:
- 攻撃力: 250-600
- 錬成コスト: 2000G + 上級素材×5
- 錬成時間: 2時間
```

### エンチャントコスト
```
+1〜+3: 100G×レベル + 強化石×1 (成功率100%)
+4〜+6: 300G×レベル + 強化石×2 (成功率95%〜85%)
+7〜+10: 500G×レベル + 強化石×3 (成功率80%〜70%)
```

### 冒険者・派遣報酬
```
森林派遣（1時間）:
- 基本報酬: 200-400G
- 素材: 基本素材×1-3
- 必要武器レベル: +0〜+3

洞窟派遣（2時間）:
- 基本報酬: 500-800G
- 素材: 中級素材×1-2
- 必要武器レベル: +3〜+6

山岳派遣（4時間）:
- 基本報酬: 1000-1500G
- 素材: 上級素材×1
- 必要武器レベル: +6〜+10
```

## 6. MVPの成功判定基準

### 定量指標
```
ユーザー継続率:
- Day1: 70%以上
- Day3: 50%以上  
- Day7: 30%以上

セッション指標:
- 平均セッション時間: 8-12分
- 日次セッション数: 3-5回
- 月次継続率: 15%以上

課金指標:
- 課金率: 3%以上
- ARPU: 100円以上
- LTV: 500円以上
```

### 定性指標
```
ユーザーフィードバック:
✅ ゲームの基本的な面白さが伝わるか
✅ 操作が直感的で分かりやすいか
✅ 課金が強制的でなく自然か
✅ 放置要素と操作要素のバランスが良いか

技術的検証:
✅ システムが安定して動作するか
✅ データ同期が正常に機能するか
✅ 拡張性に問題がないか
```

## 7. MVPから本格版への移行計画

### Phase2で追加予定の機能
```
優先度高:
1. 属性システム（火・氷・雷）
2. ランキング機能
3. 武器アビリティ（基本版）
4. 新モンスター（3種類追加）

優先度中:
5. ソーシャル機能（フレンド）
6. 武器分解・改造
7. 季節イベント（簡易版）
8. 自動化機能拡張

優先度低:
9. ギルドシステム
10. 高度なエフェクト
11. プレイヤー生成コンテンツ
```

### 移行時の考慮事項
```
データ移行:
- MVPユーザーデータの完全保持
- 新機能への自然な誘導
- 既存バランスへの影響最小化

コミュニティ:
- 初期ユーザーの特別扱い
- フィードバック反映の明示
- 継続的な改善コミットメント
```

---

このMVP設計により、最小限のリソースで核心的なゲーム体験を提供し、市場での検証を行いながら段階的に拡張していくことができます。特に重要なのは、後の拡張を妨げない技術基盤を最初から構築することです。
