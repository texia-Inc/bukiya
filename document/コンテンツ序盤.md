## 2. 各コンテンツ詳細仕様

### 2.1 冒険者システム仕様

#### 冒険者パラメータ詳細
```
基本ステータス:
- 名前: ランダム生成（100パターン）
- レベル: 1-100（段階的解放）
- 職業: 戦士、魔法使い、弓手、盗賊
- 性格: 慎重、大胆、ケチ、気前良い

来訪パターン:
- 基本頻度: 15-45分間隔
- 同時最大数: 3人（店舗レベルに依存）
- 滞在時間: 30分-2時間
- 緊急度: 通常、急いでる、余裕あり

要求パラメータ:
- 武器種: 特定/なんでも
- 最低攻撃力: レベル×20-50
- 最高予算: レベル×50-200
- 属性希望: なし/特定属性
```

#### 信頼度システム詳細
```
信頼度レベル:
0-20: 新規客（基本価格）
21-40: 知り合い（5%価格上昇）
41-60: 常連客（10%価格上昇＋特別依頼）
61-80: 信頼客（15%価格上昇＋レア素材持参）
81-100: 親友（20%価格上昇＋特別報酬）

信頼度変動要因:
+3: 希望通りの武器提供
+5: 予算以下で良い武器提供
+1: 普通の取引完了
-2: 期待に応えられない武器
-5: 取引拒否・失敗
-10: 約束破り・詐欺的行為

特別効果:
信頼度60+: 新エリア情報提供
信頼度80+: 限定素材の売却
信頼度100: 専用クエスト発生
```

#### 派遣システム詳細
```
エリア別設定:
森林エリア（解放レベル: 1）:
- 推奨武器攻撃力: 50-150
- 派遣時間: 30分-2時間
- 成功率: 70-95%
- ドロップ: 基本素材、Common武器

洞窟エリア（解放レベル: 5）:
- 推奨武器攻撃力: 100-300
- 派遣時間: 1-4時間
- 成功率: 50-80%
- ドロップ: 中級素材、Rare武器

山岳エリア（解放レベル: 10）:
- 推奨武器攻撃力: 250-500
- 派遣時間: 2-8時間
- 成功率: 30-70%
- ドロップ: 高級素材、Epic武器

成功率計算式:
基本成功率 = エリア基本値
武器適正度 = min(武器攻撃力/推奨攻撃力, 1.5)
冒険者レベル補正 = 1 + (冒険者レベル-1) × 0.02
最終成功率 = 基本成功率 × 武器適正度 × レベル補正
```

### 2.2 武器・錬成システム仕様

#### 武器ステータス計算
```
基本攻撃力算出:
min_attack = base_min × rarity_multiplier
max_attack = base_max × rarity_multiplier
actual_attack = random(min_attack, max_attack)

エンチャント効果:
final_attack = base_attack + enchant_level × enchant_rate
enchant_rate = 1.0 (基本) + rarity_bonus

レア度ボーナス:
Common: +0
Rare: +0.1 (エンチャント効果10%増)
Epic: +0.2 (エンチャント効果20%増)
Legendary: +0.3 (エンチャント効果30%増)
Mythic: +0.5 (エンチャント効果50%増)
```

#### エンチャント詳細仕様
```
成功率計算:
+1〜+5: 100% (失敗なし)
+6〜+10: 90%, 85%, 80%, 75%, 70%
+11〜+15: 65%, 60%, 55%, 50%, 45%
+16〜+20: 40%, 35%, 30%, 25%, 20%
+21+: 15%以下（段階的減少）

失敗時の効果:
+1〜+10: 素材とゴールドのみ消失
+11〜+15: 上記 + 10%の確率でレベル-1
+16〜+20: 上記 + 20%の確率でレベル-1
+21+: 上記 + 30%の確率でレベル-2

コスト設計:
Gold = 100 × (current_level + 1)²
基本強化石 = ceiling(current_level / 3)
上級強化石 = ceiling((current_level - 10) / 2) (Lv11+)
特別素材 = 1 (Lv16+)

保護システム:
保護スクロール使用:
- レベル下降を100%防止
- コスト: エンチャント費用×3
- ジェムでの購入も可能
```

### 2.3 経済システム仕様

#### 価格設定メカニズム
```
武器販売価格:
base_price = attack_power × rarity_multiplier × 2-5
rarity_multiplier:
- Common: 1.0
- Rare: 2.5  
- Epic: 5.0
- Legendary: 10.0
- Mythic: 25.0

市場価格変動:
daily_fluctuation = ±10% (ランダム)
supply_demand_factor = 0.8-1.2
event_modifier = 0.7-1.5 (特別イベント時)

final_price = base_price × daily_fluctuation × supply_demand × event_modifier

冒険者の予算設定:
min_budget = adventurer_level × 30
max_budget = adventurer_level × 80
personality_modifier:
- ケチ: ×0.8
- 普通: ×1.0  
- 気前良い: ×1.3
```
