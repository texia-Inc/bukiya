## 2. ドラゴン討伐システム設計

### 2.1 ドラゴン討伐の全体フロー

#### 討伐イベントの発生
```
ドラゴン出現の流れ:
📢 予兆段階 (1週間前):
「古代遺跡で異変が...」
「強大な気配を感じる冒険者が増加」
「ドラゴンの目撃情報が各地で」

🚨 確定段階 (3日前):
「古代ドラゴンが復活！」
「討伐隊結成の呼びかけ」
「参加冒険者の募集開始」

⚔️ 準備期間 (3日間):
プレイヤーは信頼できる冒険者を選び、
最高の装備を準備して送り出す

🐉 討伐実行 (1日):
全サーバーの参加冒険者による
リアルタイム協力バトル

🎉 結果・報酬 (数日):
オークション開催、報酬分配、
参加者への特別な称号付与
```

#### 参加資格システム
```
冒険者の参加条件:
✅ レベル20以上
✅ プレイヤーとの信頼度60以上
✅ 特定のクエスト完了
✅ 必要装備の条件クリア

✅ 店舗レベル15以上
✅ 参加冒険者が1人以上
```

## 4. 経済・バランス設計

### 4.1 オークション経済の健全性

#### 価格形成メカニズム
```
開始価格設定:
基準価格 = アイテム基本価値 × 希少性倍率
希少性倍率:
- 通常ドロップ: 1.0倍
- レアドロップ: 3.0倍
- 超レアドロップ: 10.0倍
- 一点物: 50.0倍

価格上昇制限:
- 1回の入札上昇: 前回の5-20%
- 最大入札額: 開始価格の1000%
- 時間経過による価格下降オプション

手数料システム:
- 落札手数料: 落札価格の5%
- 出品手数料: 開始価格の2%
- 運営費: 総取引額の1%
```

```
インフレ対策:
💰 ゴールドシンク強化
```
