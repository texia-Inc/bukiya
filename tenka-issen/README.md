# 天下一閃（TENKA ISSEN）

戦国無双風の、斜め見下ろし3D・棒人間の一騎当千アクション（ブラウザゲーム）。
`dist/index.html` をブラウザで開くと遊べる（Three.js を CDN から読み込むのでネット接続が必要）。

## 遊び方

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | WASD / 矢印 | 画面左側をドラッグ |
| 通常攻撃 | J | 攻 |
| チャージ攻撃 | K | 溜 |
| ジャンプ（空中で J / K でジャンプ攻撃） | Space | 跳 |
| 回避 | Shift | 回避 |
| 無双奥義（ゲージ満タン時） | L | 無双 |
| 一時停止 | P / Esc | \|\| |

## 内容

- **武将4人**（武器ごとに技がすべて違う）
  - 天城 迅（刀）：衝波・突進斬・旋風・烈破・地裂／無双「天下一閃」
  - 鷹宮 千代（槍）：昇竜突・連突・大薙ぎ・突撃・旋槍嵐／無双「千本桜突き」
  - 岩鉄 豪（大太刀）：通常攻撃中もひるまない。叩き割り・天衝・大旋風・地割れ・大爆砕／無双「鬼神大断」
  - 白鷺 凛（弓）：矢・貫き矢・扇射ち・爆蹴・雨矢・大火矢／無双「天弓・雨月」
- **動き**：ジャンプ攻撃と急降下、打ち上げた敵の回転・地面でのバウンド、決め手の吹き飛ばし、無双奥義のカットインとスロー演出、ヒットストップ、画面の揺れ
- **味方と戦況**：味方の兵と武将が自動で砦へ攻め込む。戦況ゲージ（士気）で両軍の強さと増援の速さが変わる
- **任務**：味方武将が窮地になると「救援」、敵将が本陣へ向かうと「本陣防衛」。本陣に敵将が10秒居座ると敗北
- **合戦3つ**：初陣・黒鉄峠／朱雀川の渡河戦（橋でしか川を渡れない）／決戦・鬼哭ヶ原。前の合戦に勝つと次が解放される
- **会話**：出陣前の軍議と、合戦中の掛け合い（伏兵、総大将の本気など）
- **成長**：武将ごとにレベル（最大30）。体力と攻撃力が上がる。合戦の評価（S/A/B/C）と一緒にブラウザに保存
- **音**：音源ファイルを使わず WebAudio で合成。都節音階の笛・三味線・太鼓の BGM（通常・総大将戦・勝敗）と効果音、法螺貝

## ファイル構成

```
shell.html      画面の HTML と CSS（メニュー・タッチボタン）
src/core.js     ユーティリティ、入力、セーブ
src/audio.js    効果音と BGM の合成
src/data.js     兵種、武将、技表（MOVES）、合戦データ（STAGES）
src/game.js     合戦の状態、ダメージ、飛び道具、兵の AI、増援、任務、イベント、士気
src/player.js   プレイヤー操作（攻撃、ジャンプ、回避、無双）
src/render3d.js Three.js による描画（棒人間、背景、エフェクト、カメラ）
src/hud.js      画面表示（体力、戦況、ミニマップ、会話、カットイン）
src/ui.js       画面遷移、武将選択、結果、メインループ
build.py        src を1つの HTML にまとめて dist/ に出力
```

`python3 build.py` で `dist/index.html`（単体で動く）を作る。

### 調整のしかた

- 技の威力・範囲・フレーム：`src/data.js` の `MOVES`
- 敵の強さ：`KIND`（兵種）と各合戦の `diff`（難易度倍率）、`archerRate`（弓兵の割合）
- 合戦の配置やイベント：`STAGES`。`events` の `at` は `{ t: 秒 }`／`{ bases: 残り砦数 }`／`{ bossHp: 割合 }`

### 動作確認

URL の末尾に `#debug` を付けると `window.TK` からゲーム状態を操作できる（自動テスト用）。

## 公開（GitHub Pages）

`main` ブランチの `tenka-issen/` が変わると、`.github/workflows/tenka-issen-pages.yml` が `build.py` を実行し、`dist/` を GitHub Pages に公開する。

最初の1回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
公開先は `https://texia-inc.github.io/bukiya/`。Actions タブの「天下一閃を GitHub Pages に公開」から手動でも実行できる。
