# 主人公（汐見ナギ・制服）を VRoid Studio で作る手順

下絵：`design/06_turnaround_uniform_fixed.png`（全身4面）、`design/07_expressions_uniform.png`（表情）、`design/05_props.png`（小物）。
VRoid Studio は https://vroid.com/studio から無料で入手できる（Mac 版あり）。

## 1. 新規作成
- 「新規作成」→ **女性** を選ぶ。

## 2. 顔
| 項目 | 目安 |
|---|---|
| 輪郭 | 丸みのある卵形。あごは少し短め |
| 目 | 大きめ、少したれ目（目尻を下げる） |
| 瞳の色 | 琥珀色 `#D9962B` 前後。ハイライトは控えめ |
| 肌 | うっすら日焼け `#E8B48F` 前後 |
| まゆ | 自然な太さ、少し上がり気味 |
| 絆創膏 | 顔のテクスチャに右ほほ（向かって左）にだけ描く。鼻には描かない |

## 3. 髪
- 色：黒に近いこげ茶 `#2A211C`、毛先だけ少し明るく `#6B4A2F`（グラデーションは弱め）。
- 前髪：流し前髪（右から左へ）。アホ毛を1本。
- 横髪：あごぐらいまで、細い束を1〜2本。
- 後ろ髪：**高い位置のポニーテール**。肩甲骨の下ぐらいまでの長さ。
- 揺れもの：ポニーテールと横髪に揺れを付ける（VRoid の髪の揺れの設定）。
- シュシュ：髪の結び目に、水色 `#9CC3E6` のシュシュ。アクセサリーがなければ、髪の房を輪にして作ってもよい。
  ゲームでは別の部品（`W_scrunchie`）にするので、色だけ合っていれば形はあとで差し替えられる。

## 4. 体
- 身長：157cm（VRoid の身長スライダーで合わせる）。
- 体型：細すぎない、運動している子の体つき。胸は控えめ。

## 5. 服（制服）
VRoid の服は「トップス／ボトムス／くつ下／くつ」に分かれている。この分かれ目がそのままゲームの着せ替え部品になる。

| 部品 | 中身 | 色 |
|---|---|---|
| トップス | 白い半袖のシャツ（えり付き、すそはスカートに入れる） | `#F6F5F1` |
| ネクタイ | 水色と紺のななめのストライプ | `#8FB8E0` / `#2D3A6A` |
| ボトムス | ひざ丈のプリーツスカート、紺のチェック | `#2C3557` 地に `#6F8FB5` の線 |
| スカートの下 | 黒いスパッツ（ボトムスの中に作れない場合は、くつ下の層で太ももまでの黒を描く） | `#1D1D20` |
| くつ下 | 紺のクルーソックス（すねの中ほど） | `#2D3A6A` |
| くつ | 茶色のローファー | `#6B4330` |
| 小物 | 左手首に黒いリストバンド | `#1D1D20` |

**着せ替えのための注意**
- 色を変えたい服（シャツ、スカート、くつ下）は、柄や陰影だけを描いて、**地の色は白っぽく**しておくと、ゲームで色を乗せやすい。
  分かりにくければ、まずは上の色のままでよい。あとで Blender のスクリプトで白に直せる。
- スカートの揺れもの（VRoid のスカートの揺れの設定）はオンにする。

## 6. 表情
VRoid の標準の表情（まばたき、喜び、怒り、悲しみ、驚き）はそのまま使う。
`07_expressions_uniform.png` を見て、目の形を少し調整する。ドヤ顔は Blender であとから足す。

## 7. 書き出し
- 「撮影・エクスポート」→ **VRM 1.0** で書き出す。
- ポリゴン削減：髪の削減を「中」ぐらい、テクスチャは **2048px**、マテリアルの数は **少なめ（8前後）**。
- 書き出したファイルを `tools/umimachi/design/nagi.vrm` として置く。

## 8. このあと（Claude がやること）
1. `nagi.vrm` を Blender に読み込み、服を `W_tops`・`W_tie`・`W_skirt`・`W_socks`・`W_shoes` などの部品に分け、名前をそろえる。
2. 今の着せ替え部品（パーカー、魔女の帽子、ねこ耳など）を新しい体に合わせて移す。
3. `heroine.glb` を作り直し、`src/p4c_wardrobe.js` に制服を登録する。
4. スケボー、カメラなどの小物（Tripo で作る）を組み込む。
