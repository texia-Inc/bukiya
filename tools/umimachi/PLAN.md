# 海街スケート これからの計画

大事にすること：
- 引っかからない
- 目標がすぐわかる
- 新しい場所や景色が開けていく

## 1. 鏡の海の専用ステージを増やす

地図の「？」の島を、本物のステージにします。島ごとに、景色とルールを1つずつ新しくします。

| 島 | 景色 | 新しいルール |
|---|---|---|
| 4. 星の浅瀬 | 夜空が海にうつる | 光の線で星のかけらを囲んで集める |
| 5. 花の島 | 花びらが舞う昼の島 | 影を囲むと花が咲き、島が色づいていく |
| 6. 嵐の海 | 波で足場が上下する | 海の主との最後の勝負 |

- しくみ：今の `STG`（`p5u_stage.js`）に島を足します。地図、星、ごほうびはそのまま使えます。
- 大きさ：小〜中くらいです。いちばん早くできます。

## 2. 海街の外のおつかい

すでに行ける場所を使います。
- 山のふもと（電車で行く）
- 灯台の島（舟で行く）

しくみ：
- 「受けとる → とどける」だけの、短いおつかいです。
- 行き先までは光の道が出るので、迷いません。
- 星は3つです：とどける、早くとどける、転ばない。
- ごほうびはお金と服です。その場所でしか手に入らないもの（山の野菜、島の貝など）ももらえます。

例：
- 山：峠の上の展望台から駅まで、お弁当を下りでとどける
- 山：田んぼのおばあちゃんの野菜を、農家3軒に配る
- 島：漁師さんの網を灯台守へとどける
- 島：灯台の上から、桟橋で待つ子に手紙をとどける

- 数：まず各場所に3つ、合わせて6つ。
- 大きさ：中くらいです。今のおつかいのしくみ（`QUESTS`）が使えます。

## 3. ほかの人とのスケボー競争

相手は町のスケボー仲間3人で、それぞれ得意な走りかたがあります。

しくみ：
- コースに光の門が並んでいて、順番にくぐってゴールします。
- 相手とはぶつからず、すりぬけます。
- 手すりや屋根を使った近道があります。技を決めると少し速くなります。
- 相手は、先に行きすぎず、離されすぎないように速さを合わせます。
- 順位で星がもらえて、1位になると次のコースが開きます。

コース：
1. 神社から浜まで、坂の下り
2. 商店街ぬけ（屋根と手すりが多い）
3. 夜の峠（山のふもと）

- 大きさ：大きいです。相手の走りを新しくつくります。峠の車との勝負とは別のものです。

## おすすめの順番

1. 専用ステージ：早くできて、遊べる島がすぐ増えます。
2. 外のおつかい：山と島に行く理由が増えます。
3. 競争：いちばん大きいので最後にします。
